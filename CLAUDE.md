# Cardume - Landing Page

Este é o site estático do projeto Cardume, hospedado em card-u.me.

- **Tecnologia:** HTML/CSS/JavaScript puro (sem frameworks, sem build tools)
- **Propósito:** Landing page do app + páginas de suporte (privacy, safety, delete-account)
- **Hospedagem:** Site estático — editar os arquivos e fazer deploy diretamente

Ao trabalhar aqui, lembre-se:
- Manter design responsivo (mobile-first, testar em telas pequenas)
- Não introduzir dependências externas ou build steps — tudo deve funcionar abrindo o HTML direto no browser
- Foco em conversão: CTAs para App Store e Google Play são o objetivo principal
